# ADR 0008. Хранилище медиафайлов

- **Status:** accepted
- **Date:** 2026-10-16
- **Decision-maker(s):** Aleksandr
- **Owner:** Aleksandr
- **Scope:** Платформа (общее)

## Контекст

Контент платформы включает следующие медиа: изображения (карточки, подпись изображения), аудио, видео, документы (в т.ч. материалы для ИИ-генерации наборов). Такие загруженные файлы нужно где-то хранить. Для этого существуют специаилизированные объектные хранилища.

Нужно решить, разворачиваем собственный контейнер или кластер объектного хранилища или берём managed. 

Если медиа содержат персональные данные - по 152-ФЗ хранение на территории РФ.

## Рассмотренные варианты

1. **Self-hosted (S3-совместимое, напр. MinIO).** Полный контроль, данные остаются у нас, не платим деньги посредникам. Минусы: обслуживание ещё одного компонента в системе; поднимаем и сопровождаем ещё один инфраструктурный компонент.
2. **Managed object storage.** Надёжность, масштабирование и бэкапы - на провайдере (cloud.ru, Yandex Object Storage и прочие, доступ по S3 API). Быстрый старт, на старте есть бесплатный тир. Минусы: данные хранятся у провайдера; тариф диктует ограничения на загрузку/хранение/передачу; привязка к поставщику (отчасти облегчается повсеместной интеграцией S3 API).

## Решение

Берём **managed object storage, S3-совместимое**, своё хранилище не держим.

Кандидат - cloud.ru (РФ-провайдер). Бесплатный тир на старте (в месяц): первые 15 ГБ объёма, 100 000 операций LIST/POST/PUT, 1 000 000 операций GET/HEAD.

- Обязательное требование: хранение в РФ;
- Доступ по S3 API - переносимость между провайдерами и self-hosted решениями.

## Последствия

- Не держим своё хранилище; надёжность, масштабирование и бэкапы - на провайдере.
- Бесплатный тир покрывает старт; сверх лимитов (объём и число операций) - платно.
- Данные хранятся у провайдера и должны быть размещены в серверах на территории РФ.
- S3-совместимость снижает привязку к конкретному поставщику: смена провайдера или переход на self-hosted MinIO не заставит переписывать систему с нуля.
- На C4-Context external system «Объектное хранилище» - это выбранный провайдер.
