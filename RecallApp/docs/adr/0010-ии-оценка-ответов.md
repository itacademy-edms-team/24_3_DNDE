# ADR 0010. ИИ-оценка свободных ответов

- **Status:** accepted
- **Date:** 2026-10-17
- **Decision-maker(s):** Aleksandr
- **Owner:** Aleksandr
- **Scope:** Платформа (общее)

## Контекст

Свободные ответы (Free recall, ввод с нечёткой сверкой) нужно оценивать как верно / частично / неверно. Точная и нечёткая сверка по эталону покрывает простые случаи, но не смысловую эквивалентность свободного текста исходному. Использование LLM позволяет получить семантическую оценку ответа.

Это открытый вопрос: качество, стоимость, когда включать (§4.6, §7.3). Фича **вне 8-месячного горизонта**. Оценку, в отличие от генерации наборов, выполняет **сам сервер** (исходящий вызов LLM), а не внешний агент (ADR 0005).

Ответы пользователя могут содержать персональные данные - при отправке в LLM это должно учитываться (152-ФЗ).

## Рассмотренные варианты

1. **Только эталонная/нечёткая сверка (без ИИ).** Дёшево, детерминированно, данные не уходят наружу. Минус: не оценивает смысловую эквивалентность свободного текста - часть форматов остаётся без адекватной проверки.
2. **Своя модель (self-hosted LLM).** Контроль, данные у себя. Минус: дорого в эксплуатации и обслуживании, качество своей модели будет всегда ниже топовых. Для масштаба платформы нереалистично.
3. **Внешний LLM-провайдер (API).** Качество топовых моделей без своей инфраструктуры, оплата по факту. Минус: ответы уходят провайдеру и хранятся на их серверах; стоимость за токены; зависимость от провайдера.

## Решение

На старте свободные ответы проверяются **эталонной/нечёткой сверкой** (вариант 1). ИИ-оценка - отдельная фича вне горизонта.

Когда дойдём: оценку делает **серверный вызов внешнего LLM-провайдера** (вариант 3). Конкретный провайдер и модель фиксируются позже. Доступ к ИИ-оценке - **часть платной подписки** (см. PDR «Монетизация»).

## Последствия

- На старте ИИ-оценки нет; свободные ответы проверяются эталонной/нечёткой сверкой (§4.6).
- При включении - исходящий серверный вызов LLM. Это отличный от ADR0005 сценарий.
- Платная фича, завязаная на PDR «Монетизация».
- Ответы пользователя уходят провайдеру -> до включения оформить 152-ФЗ (РФ-локализованный провайдер, либо согласие/анонимизация).
- Стоимость за токены и зависимость от провайдера.
- На C4-Context external system «ИИ-сервис (LLM)» - это выбранный провайдер, на который приходится исходящий вызов.
