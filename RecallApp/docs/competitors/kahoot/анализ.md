# Анализ конкурента: Kahoot! — функционал (по ролям)

> Описание функционала Kahoot! по направлениям: **Участник (игрок)**, **Организатор (учитель/создатель)**, **Общие сведения**. Решения по собственной реализации — в [Плане платформы](../../platform/План%20платформы.md). Kahoot! — главный референс по геймификации для платформы.
> Данные — из публичных страниц `kahoot.com` и живого продукта под аккаунтом Teacher (Higher Education, бесплатный тариф). Вскрыты вживую: редактор, каталог типов вопросов с free/premium-гейтингом, режимы запуска, **полный live-матч (хост + гость), хост-консоль, отчёт**, Groups, details-страница. Границы знания — в C.4.

# A. Участник (игрок)

Тот, кто играет. Аккаунт не обязателен — можно войти в игру гостем.

## A.1. Вход в игру

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Присоединение по PIN** | На `kahoot.it` игрок вводит **Game PIN** (генерит хост при запуске live), затем ник. Попадает в лобби до старта. | Матч/сессия, PIN, Игрок(ник) |
| **Присоединение гостем** | Без регистрации: только ник. Аккаунт нужен только хосту/создателю. | Игрок (анонимный) |
| **Кастомный ник + музыка** | Настраиваемый ник участника; фоновая музыка лобби и громкость — настройка хоста (платно по тарифу). | Сессия |
| **Командный режим** | Игроки могут играть индивидуально или **командами** (team mode). | Команда, Игрок×Команда |

## A.2. Геймплей live (пройден вживую)

Паттерн Kahoot: **вопрос на общем экране хоста**, варианты ответа на устройстве игрока — **цветные фигуры** (ромб/треугольник/круг/квадрат). Пройдена реальная сессия хост+гость, цикл подтверждён.

Поток (вскрыт): `kahoot.it` → ввод PIN (`/join`) → ник («Do not use your real name») → **«You're in!»** (`/instructions`) → **«Get Ready!»** → вопрос.

| Элемент | Как работает (вживую) | Сущности/данные |
|------|--------------|------------------|
| **Ответ на устройстве** | На устройстве игрока — **только цветные фигуры, без текста варианта** (для True/false — 2 фигуры: Blue diamond / Red triangle). Текст вопроса и вариантов на экране хоста. Хост-тумблер «Show questions on devices» дублирует Q+A на устройства. | Вопрос, Ответ, Сессия |
| **Экран игрока** | Заголовок с таймером («29 seconds left»), № вопроса (Quiz 1 of 25), имя игрока + текущие очки, аватар-персонаж. | Игрок, Сессия |
| **Результат ответа** | Сразу после ответа — экран **Correct / Incorrect** (`/answer/result`). | Ответ |
| **Очки за скорость+правильность** | Неверный ответ = **0 очков** (подтверждено: Tester1 → 0). Верный даёт баллы по скорости. Хост-настройка Points: Standard / Double / No points. ⚠️ точная формула скорости не вскрыта. | Сессия (очки) |
| **Лидерборд между вопросами** | На экране хоста после вопроса — таблица с именем+очками игроков; хост листает Next / Previous question. В конце — подиум + ranking на устройстве (`/ranking`). | Лидерборд, Сессия |
| **Join в ходе игры** | Кнопка Join и PIN остаются доступны после старта — опоздавшие могут подключиться. | Сессия |
| **Аватар/персонаж** | Игроку автоматически назначается персонаж (напр. «Frog with Top hat»); хост-опция Characters даёт игроку выбрать и кастомизировать. | Игрок |

## A.3. Самостоятельный режим (assigned / student-paced)

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Assigned challenge** | Хост назначает kahoot как домашку/повтор. Вопросы и ответы — на экране самого игрока, таймер можно отключить. Игрок проходит в своём темпе. | Задание, Игрок, Прогресс |
| **Flashcards (study)** | Самостоятельное изучение карточками (отдельный self-study опыт, не live-игра). | Карточка |

# B. Организатор (учитель / создатель)

Требует аккаунт. Создаёт контент, хостит live, назначает, смотрит отчёты. Редактор и хост-консоль вскрыты вживую (под free Teacher-аккаунтом).

## B.1. Создание контента

> Статус: редактор и 5 способов создания вскрыты вживую (детали в B.2). ИИ-генерация, «Combine kahoots», импорт из таблицы — заявлены, вживую не прогонялись.

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Создание kahoot с нуля** | Редактор вопросов: добавить слайды, выбрать тип вопроса, варианты (quiz — до 120 символов), картинка/видео YouTube, таймер, баллы. | Kahoot (набор вопросов), Вопрос |
| **Шаблоны и банк вопросов** | Старт из готового шаблона; микс из банка вопросов (заявлено «полмиллиарда» вопросов сообщества). Создание «до 3× быстрее». | Шаблон, Банк вопросов |
| **Дублировать/редактировать чужой** | Копировать и править существующие kahoot (свои и публичные). | Kahoot |
| **Импорт из таблицы** | Импорт вопросов из spreadsheet. | Вопрос |
| **«Combine kahoots»** | Объединить несколько наборов в один. | Kahoot |
| **ИИ-генерация** | Создание контента из темы / URL / статьи Wikipedia / файлов (PDF/PPT/DOCX до 150 стр.) / скана рукописных заметок (в приложении) / импорта слайдов. ИИ-форматы: quiz, true/false, question extractor, micro-lesson, vocabulary, presentation. По тарифу. | LLM-пайплайн, Вопрос |
| **Медиа/оформление** | Библиотека изображений, вставка YouTube, расширенные макеты слайдов, фон, логотип/маскот школы. | Вопрос, Тема оформления |

## B.2. Редактор вопросов (вскрыт вживую)

`/creator`. Старт из диалога «Create new kahoot» — **5 способов**: PDF→kahoot (ИИ), Topic→kahoot (ИИ: topic/URL/Wikipedia), Blank canvas, Import slides (🔒 premium), Templates.

Экран вопроса: заголовок, медиа (поиск/вставка YouTube/Upload/drag), 2 обязательных + 2 опциональных ответа, **«Add more answers» 🔒 premium**, отметка верного/неверного, Image library на каждый ответ. Панель «Question properties»:

| Настройка | Опции |
|-----------|-------|
| **Question type** | Выпадающий список, см. B.3 |
| **Time limit** | Выпадающий (дефолт 20 сек) + «Apply to all questions» |
| **Points** | **Standard / Double points / No points** (3 опции) |
| **Answer options** | **Single select / Multi select** |
| Прочее | Themes (оформление), Duplicate/Delete вопроса |

## B.3. Каталог типов вопросов (14, с гейтингом на free-аккаунте)

Главное отличие от Quizlet: **богатый набор интерактивных форматов**, не только карточки. На бесплатном Teacher-аккаунте доступны лишь 3; остальные 11 — 🔒 premium. Сгруппированы в UI в 3 блока.

| Блок | Тип | Назначение | На free |
|------|-----|------------|---------|
| **Test knowledge** | Quiz | Множественный выбор (до 4 ответов). | ✅ |
| | True or false | Верно/неверно. | ✅ |
| | Type answer | Ввод текста без подсказок. | 🔒 |
| | Slider | Ответ на шкале. | 🔒 |
| | Pin answer | Точка на изображении. | 🔒 |
| | Puzzle | Расставить в порядке. | 🔒 |
| **Collect opinions** | Poll | Опрос без правильного ответа. | 🔒 |
| | Scale | Оценка по шкале (напр. согласие). | 🔒 |
| | NPS scale | NPS-шкала. | 🔒 |
| | Drop pin | Метка на изображении (опрос). | 🔒 |
| | Word cloud | Облако слов из ответов. | 🔒 |
| | Open-ended | Свободный текстовый ответ. | 🔒 |
| | Brainstorm | Сбор и группировка идей. | 🔒 |
| **Present info** | Slide | Контентный слайд без вопроса. | ✅ |

> Free-аккаунт урезан по лимиту участников, **типам вопросов, доп. ответам, импорту слайдов, ИИ** — всё помечено premium-значком прямо в UI. Апселл встроен в каждый экран.

## B.4. Режимы запуска (вскрыты на details-странице)

Каждый kahoot запускается 6 способами, в 2 корзины:

| Корзина | Режим | Суть |
|---------|-------|------|
| **Kahoot session** (с хостом) | **Host live** | Вопросы на большом экране, ответы на устройствах. Генерит Game PIN. Realtime. |
| | **Lecture** | Интерактивный слайдшоу, хост задаёт темп. |
| | **Assign** | Отправить участникам (student-paced, домашка/повтор). |
| **Kahoot self-study** (без хоста) | **Learn** | Самостоятельное прохождение. |
| | **Flashcards** | Карточки: запомнить/закрепить. |
| | **Play solo** | Self-paced quiz-игры одному. |

> На free-аккаунте details-страница показывает **«Max. 10 participants» + «Upgrade for more»** (маркетинговый Go заявляет 40 — на реальном free-Teacher лимит жёстче). Шаринг в Microsoft Teams / Google Classroom / Remind / Apple Schoolwork (заявлено).

## B.5. Хост-консоль live (вскрыта вживую)

`play.kahoot.it`. При Host live — экран **«Choose game mode»**: выбор **experience** (визуальный режим поверх того же набора вопросов). Фильтры: All / Assessment / Repetition / Team competition / Collaboration / Unplugged.

**Каталог experiences (видно на free, часть под 🔒):** Classic, Classic: Unplugged, Team Tiles, Lecture, Teams, Accuracy, Confidence (доп. очки за уверенность), + **игровые миры-скины**: Marble Race, Robot Run, Lost Pyramid, Submarine Squad, Cosmic Conquest, Color Kingdoms, Treasure Trove, Tallest Tower, Chill Art, сезонный Halloween.

**Лобби:** крупный Game PIN + «Join at kahoot.it», QR, список участников с аватарами, Lock game, kick участника, Start.

**Game options (во время игры):**

| Группа | Опции |
|--------|-------|
| Отображение | Show questions on devices, Characters (выбор/кастом персонажа) |
| Themes | Standard, Spring + 🔒 (Year of the Horse, Sweet treats; всего 8) |
| General | Language, Lobby music |
| Accessibility | Increase contrast, Unlimited time 🔒 |
| Hosting | Lock game, Reactions, Randomize questions 🔒, Randomize answers, Autoplay, Q&A 🔒, QR/Copy link, Allow team selection 🔒 |
| Learning | Team talk 🔒 |
| Security | Nickname generator 🔒, 2-step join |
| Завершение | **End now** |

**Управление ходом:** Next / Previous question; после каждого вопроса — результаты и лидерборд; в конце — gameover (Podium, Session summary, Get feedback, Play again).

## B.6. Отчёты (вскрыты вживую)

После сыгранной сессии в `/reports/kahoots/` появляется строка: название, **«Live session • Classic mode»**, число вопросов, число игроков, дата, меню действий. Отчёт (`/reports/new-live-game/<...>/summary`):

| Элемент | Содержимое |
|---------|-----------|
| Вкладки | **Participants** (N), **Questions** (N), **Time** |
| Сводка-карточки | **Difficult questions**, **Need help** (игроки с низкой точностью), **Didn't finish** |
| Метрики | Точность по вопросам/игрокам (`averageAccuracy`), число неотвеченных (`unansweredCount`) |

> Базовый отчёт доступен и на free. Advanced-трекинг во времени, spreadsheet-экспорт, объединение — по старшим тарифам (заявлено).

## B.7. Организация

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Библиотека** (`/my-library/kahoots/all`) | Свои kahoot и папки. | Kahoot, Папка |
| **Discover** (`/discover`) | Публичный каталог готовых kahoot (каналы verified-создателей: NASA, Britannica, WWF…), поиск по тегам/предметам. | Индекс, Канал |
| **Groups** (`/groups`) | Вкладки **Owned / Joined**, «Create group». Назначение: **Collaborate / Assign / Compete** — командная работа учителей, шаринг контента, совместная игра. | Группа, Пользователь×Группа |
| **Шаринг** | Прямой шаринг другим пользователям Kahoot, в Microsoft Teams. Favorite, Share, Follow автора. | Kahoot |

# C. Общие сведения

## C.1. Профиль

| Параметр | Значение |
|----------|----------|
| Кто | Kahoot! — игровая платформа обучения (game-based learning), live-викторины |
| Платформы | Web (`kahoot.com` — создание/хостинг, `kahoot.it` — игрок); приложения iOS/Android |
| Модель доступа | Freemium: Kahoot! Go (бесплатно) + платные тарифы |
| Сегменты | Schools (учителя/школы), Higher-ed, Work/бизнес (Kahoot! 360), Personal, EDU |
| Ключевой приём | Live-матч: вопрос на общем экране, ответ цветными фигурами (2–4 по типу вопроса) на устройстве, очки за скорость, лидерборд |

## C.2. Режимы игры (сводка)

| Режим | Суть | Для чего |
|------|------|----------|
| **Live (hosted)** | Realtime, все вместе, общий экран + устройства, PIN, лидерборд. | Класс/мероприятие |
| **Unplugged** | Один экран, консенсус-ответ, общий процент. | Без устройств у игроков |
| **Assigned (student-paced)** | В своём темпе, домашка/повтор, таймер опц. | Дистанционно/повтор |
| **Flashcards / self-study** | Карточки самостоятельно. | Индивидуальный повтор |

## C.3. Ценообразование (schools, EUR, годовая)

Freemium. Переключатель месячная/годовая; цены указаны «include tax». Лимит участников растёт с тарифом — ключевой апселл-рычаг.

| План | Цена (мес., годовой биллинг) | Лимит участников | Ключевое |
|------|------------------------------|------------------|----------|
| **Kahoot! Go** | 0 | 40 | Classic live, quiz+true/false, готовый контент, flashcards, банк вопросов |
| **Kahoot!+ Bronze (Individual)** | €4 (€44/год) | 50 | Базовые ИИ-генерации (3 стр.), review-типы, accuracy experience |
| **Kahoot!+ Silver** | €8.50–9 (€102/год) | 100 | ИИ из файлов (до 150 стр.), feedback-типы (drop pin, scale), lecture experience, game experiences |
| **Kahoot!+ Gold** | €15 (€174.50/год) | 200 | Полный ИИ-тулкит, precision-типы (slider), advanced-отчёты, AccessPass |
| **Kahoot! One** | €23 (€276/год) | 800 | Все типы вопросов, все режимы, файлы любой длины |

> Отдельные линейки: Kahoot! EDU (школы/универы), Kahoot! 360 (бизнес), Kahoot! One Ultra ($39–49/мес, крупные брендированные события). Монетизация — по **лимиту участников** + ИИ-фичи + типы вопросов + отчёты.

## C.4. Факты vs предположения

- **Проверено (вживую, под аккаунтом Teacher free):** редактор `/creator` — 5 способов создания, настройки вопроса (type/time/points/answer-options), медиа; **каталог 14 типов вопросов с free/premium-гейтингом** (free: Quiz, True/false, Slide); 6 режимов запуска; **полный live-матч хост+гость** — Choose game mode + каталог experiences, лобби с PIN, экран игрока (только фигуры), Correct/Incorrect, лидерборд, подиум/gameover; game options хоста; **отчёт** (Participants/Questions/Time + Difficult questions/Need help/Didn't finish); неверный ответ = 0 очков; free-лимит **10 участников**; Groups, Discover, Library.
- **Проверено (публичные страницы):** тарифы schools и лимиты участников; ИИ-источники генерации.
- **Предположение (не вскрыто детально):** точная формула очков за скорость (видно лишь, что скорость+верность, неверный=0); командный/teams режим изнутри; работа ИИ-генерации; платные experiences (игровые миры) в действии; spreadsheet-экспорт и advanced-отчёты (под тарифом).
- **Не проверялось (вне сетапа):** мобильные приложения, бизнес-линейка Kahoot! 360, Kahootopia (мир-награда), платные типы вопросов изнутри.

## C.5. Карта URL

- `kahoot.it` — игрок: `/` (PIN) → `/join` (ник) → `/instructions` («You're in») → `/getready` → `/gameblock` (вопрос) → `/answer/result` → `/ranking`
- `kahoot.com` — лендинг; `/schools/how-it-works/` обзор фич; `/schools/plans/` тарифы
- `create.kahoot.it` — приложение создателя (за входом):
  - `/` дашборд · `/creator` редактор · `/discover` каталог · `/my-library/kahoots/all` библиотека · `/reports` отчёты · `/groups` (`/owned`, `/joined`) · `/details/<id>` карточка kahoot (запуск) · `/profiles/<id>` · `/channel/<id>`
  - `play.kahoot.it/v2` — хост: `?quizId=&hostId=` (choose mode) → `/lobby` → `/start` → `/gameblock` → `/gameover`; Kahootopia
- Отдельные линейки: `kahoot360.com` (бизнес)
