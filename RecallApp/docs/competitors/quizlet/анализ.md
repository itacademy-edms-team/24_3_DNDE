# Анализ конкурента: Quizlet — функционал (по ролям)

> Описание функционала Quizlet по направлениям: **Ученик**, **Учитель**, **Общие сведения**. Решения по собственной реализации — в [Плане платформы](../../platform/План%20платформы.md). Профиль, ценообразование и структурный обзор — в [обзоре конкурентов](../README.md).
> Данные сняты с живого Quizlet под аккаунтами учителя и ученика.

# A. Ученик

Функционал, доступный обучающемуся.

## A.1. Ядро обучения

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Карточки (Flashcards)** | Двусторонняя карта, переворот по клику. Навигация вперёд/назад, счётчик, перемешать, автопрокрутка, полный экран, «показать подсказку». | Карточка, Прогресс (звезда) |
| **TTS / озвучка** | Кнопка «sound» читает термин/определение вслух. | Карточка + голосовой движок |
| **Тест (Test)** | Генерирует набор вопросов из модуля. Настройки: кол-во вопросов, сторона ответа (термин/определение/оба), типы: выбор (всегда вкл), верно-неверно, подбор, письменные. Показывает счёт и разбор. | Модуль, Карточка, Сессия |
| **Заучивание (Learn)** | Адаптивные раунды «до освоения». Цель сеанса: к экзамену (расписание по дням) / запомнить всё (один сеанс). Мешает типы вопросов (выбор→письменные→карточки). Неверный ответ: показывает правильный, не даёт прогресс, карта возвращается в очередь. Прогресс-бар = очки освоения, не кол-во карт. **Не классический SM-2/Anki (дневные интервалы не видны) — mastery-based.** Настройки: типы вопросов, сторона, изображения, варианты оценок, TTS, сброс прогресса. | Модуль, Карточка, Прогресс (статус+очки), Сессия |
| **Письмо (Write)** | Подрежим Learn: ввод ответа текстом. | Карточка, Сессия |
| **Правописание (Spell)** | Подрежим: диктовка + ввод, проверка орфографии. | Карточка + TTS |

## A.2. Создание контента

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Ручное создание модуля** | Форма: название, описание, список карточек (термин+определение+картинка). Добавить/удалить карточку. «Создать» / «Создать и практиковать». | Модуль, Карточка |
| **Автоподсказки определений** | При вводе термина предлагает готовые определения из внутренней базы. | Карточка + база/словарь |
| **Импорт** | Вставка готового списка карточек текстом — пары «термин–определение»; разделитель между полями и между карточками настраивается (таб / запятая / новая строка). | Карточка |
| **Диаграммы** | Карточки = точки на изображении. | Карточка + координаты |
| **ИИ-генерация карточек** | Загрузка PDF/PPT/DOCX или ввод заметок/запроса → LLM генерит карточки, предпросмотр перед добавлением. (Эта версия — работает.) | Карточка + LLM-пайплайн |

## A.3. Геймификация

Паттерн Quizlet: отдельные мини-игры поверх **одного** модуля + викторина из его карточек. Везде очки и личный рекорд. Одиночные казуалки, не XP/streak в ядре.

| Игра | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Подбор (Match)** | На поле вперемешку разложены плитки: часть с терминами, часть с определениями. Игрок кликает плитку-термин, затем её пару-определение — верная пара исчезает. Цель — убрать все пары за минимальное время. Таймер идёт на увеличение; за ошибочную пару добавляется штрафное время. | Карточка, Сессия (время) |
| **Блоки (Blocks)** | Игровое поле-сетка 8×8 (механика Block Blast / 1010). Снизу выдаются фигуры из блоков; чтобы получить следующую, нужно верно ответить на вопрос по карточке. Фигуры перетаскиваются на поле; заполненная строка/столбец «сгорает» и даёт очки. | Карточка, Сессия + игровой движок |
| **Кристаллы (Charms)** | Поле заполнено самоцветами. Удаляешь группы одинаковых (match-3), число ходов ограничено (старт — 10). Верные ответы дают доп. ходы и спецэлементы. | Карточка, Сессия + match-3 движок |
| **Blast** | Аркада на время: летят «астероиды» с вариантами ответа; показан термин, игрок сбивает астероид с верным определением. Неверный выбор/пропуск — минус. Есть скины корабля. | Карточка, Сессия (время) + аркадный движок |

## A.4. Организация и социальное

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Папки** | Группировка своих/сохранённых модулей. | Папка, Модуль |
| **Сохранить чужой модуль** | Bookmark публичного модуля себе. | Пользователь×Модуль |
| **Публичная библиотека + поиск** | Поиск по модулям/учебникам/вопросам, просмотр по предметам, «популярные», «учащиеся также изучали». | Модуль (видимость), индекс поиска |
| **Учебная группа (владелец-ученик)** | Создаёт **любой** аккаунт типа «Ученик»: «Учебные группы» → «Создать группу» (ввод только имени, создатель сразу единственный участник). Две вкладки: **Учебные материалы** (прикрепить существующие наборы через «Add a set» — выбор из недавних/поиск) и **Участники**. Приглашение — **только по ссылке, макс. 15 человек** (ни email, ни Google; предупреждение о видимости профиля принявшим). Меню группы: переименовать, пожаловаться, покинуть. По участнику: меню удаления. | Учебная группа, Пользователь×Группа, Модуль×Группа |
| **Учебная группа (участник-ученик)** | Вступление по ссылке. Общий доступ к прикреплённым наборам, совместное изучение, «отслеживание прогресса друг друга» (peer, не отчёты учителя). | Учебная группа, Пользователь×Группа |
| **Курс/класс (участник-ученик)** | Отдельная от учебной группы сущность (её владелец — учитель, см. B.1). До вступления: заход по прямой ссылке `/class/<id>` даёт кнопку **«Запрос на участие»** → статус «в ожидании утверждения администратором» (**вступление = запрос + одобрение учителя**). После вступления (проверено): видит **2 вкладки** — Учебные материалы и Участники (ростер без кнопок управления); может **добавить модуль** и **пригласить других** (email/ссылка). **Недоступно:** вкладки «Учебные инструменты» и «Прогресс», управление участниками, назначение заданий. | Курс, Пользователь×Курс |
| **Live (мультиплеер)** | Командная игра в реальном времени для класса / «играть с друзьями». | Realtime-сервер |
| **Печать / Embed** | Печать модуля в PDF; встраивание через iframe. Выделенного CSV/текст-экспорта на чужом модуле нет → мягкий lock-in. | Модуль |

> **Учебная группа ≠ курс/класс.** Тип аккаунта определяет примитив: «Ученик» получает в навигации **Учебные группы** (лёгкие, join по ссылке, макс. 15, без заданий), «Учитель» — **Курсы** (школа, задания, отчёты, см. B.1). **Учебные группы — ученический примитив:** под аккаунтом-учителем `/study-groups` редиректит на `/latest`, а переход по ссылке-приглашению учителем отклоняется («код больше не действителен»). Т.е. учитель не создаёт и не вступает в учебные группы. (Исходная гипотеза «группу создаёт и ученик, и учитель» подтвердилась лишь наполовину — только ученик.)
> ⚠️ Вид учебной группы глазами **рядового участника** (не владельца) не снят: для этого нужен **второй ученический** аккаунт (учитель не годится), а он один. Строка «участник-ученик» выведена из владельца-вида и питча.

## A.5. Смежное — не ядро запоминания

| Фича | Как работает |
|------|--------------|
| **Решения из учебников (Explanations)** | База пошаговых решений из учебников, ответы экспертов, поиск по ISBN/предметам, миллионы решений. Отдельная вертикаль (конкурент Chegg/Course Hero). Платно. |
| **Учебные руководства (Guides)** | ИИ-конспект/гайд из материала. У Quizlet пока вейтлист. |
| **Таймер «помодоро»** | Встроенный учебный таймер (25:00, график учёбы). |

# B. Учитель

Функционал аккаунта типа «Учитель». B2B/EdTech-пласт. У такого аккаунта в навигации вместо «Учебных групп» — **«Курсы»** + блок «Инструменты для учителей».

## B.1. Учительский слой

**Курс/класс — отдельная, более тяжёлая сущность, чем учебная группа (A.4).** Создаётся только из аккаунта-учителя. Сторону участника-ученика см. в A.4.

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Классы / курсы (управление)** | Учитель создаёт класс (привязан к учебному заведению+региону) и управляет им. Четыре вкладки: **Учебные материалы** (добавить/выбрать модуль), **Участники**, **Учебные инструменты** (запуск по материалам курса: игры Quizlet Live / Blast / Подбор + Карточки / Заучивание / Тесты, с предпросмотром), **Прогресс** (🔒 платно). | Курс, Пользователь×Курс, Модуль×Курс |
| **Приглашение учеников** | Три способа: Google Classroom, по ссылке, по email (массово до 200). Вступление ученика проходит через запрос + одобрение (см. A.4). | Курс, инвайты |
| **Назначение активности (задания)** | Выбор модуля + режима (Заучивание/Карточки/Тест/Подбор/Блоки/Blast) + название/примечание + срок начала/окончания → ссылка на задание, отслеживание завершения, статистика прогресса. Бесплатно, вход ученику не нужен. | Задание (модуль×режим×срок), Прогресс |
| **Отчёты о прогрессе класса** | Статистика выполнения по ученикам. 🔒 платная. | Прогресс (агрегаты) |
| **Класс-игры (Live, Blast)** | Запуск Live/Blast на класс в реальном времени. | Realtime |
| **Создать контент** | Учителю доступно создание модуля, учебного руководства и пробного теста из меню. | Модуль, Guide, Тест |

# C. Общие сведения

Не привязано к конкретной роли.

## C.1. Инфраструктура аккаунта

| Фича | Как работает | Сущности/данные |
|------|--------------|------------------|
| **Регистрация/вход** | Email+пароль, OAuth: Google, Facebook, Apple, WhatsApp; magic-link; сброс пароля. | Пользователь, провайдеры OAuth |
| **Настройки профиля** | Ник, email, фото, тип аккаунта, учебное заведение. | Пользователь |
| **Оформление** | Тема (авто/свет/тьма), язык. | Настройки |
| **Уведомления** | Учебные напоминания + новости; email-тумблеры, время, таймзона. | Настройки, планировщик |
| **Приватность/аккаунт** | Создать пароль, привязать соц-аккаунт, скрыть реальное имя, индексация в Google, удаление аккаунта. | Пользователь |

## C.2. Новые ИИ-фичи создания контента — все в ограниченном доступе

Доступны (точнее — заявлены) в обеих ролях. Три новые ИИ-фичи существуют в UI, но **не работают для обычного пользователя** (вейтлист или временно отключены). Реальной механики не вскрыть — только факт существования.

| Фича | URL | Статус (на 2026-10-02) | Что заявлено |
|------|-----|------------------------|--------------|
| **Podcast mode** | `/podcasts/generate` | ⛔ вейтлист | Аудиоподкаст из заметок (ИИ: текст→сценарий→TTS) |
| **Пробный тест (AI practice test)** | `/ai-practice-test-generator` | ⛔ «сейчас недоступны» | ИИ-генерация пробного теста |
| **Учебное руководство (Guides)** | `/study-guides/upload` | ⛔ вейтлист (ученик и учитель) | ИИ-конспект/гайд из материала |

> Базовая ИИ-генерация карточек из заметок («Create your own flashcards — Generate from your notes») — **работает**. ИИ-генерация контента — центральная текущая ставка Quizlet.

## C.3. Факты vs предположения

- **Проверено (вживую):** все режимы и игры, настройки Теста и Заучивания, создание модуля, настройки аккаунта, тарифы, способы входа, меню модуля, учительский слой (курс: все 4 вкладки, приглашение по email, приём запроса на вступление), ученический слой (создание учебной группы + её вкладки/приглашение; курс глазами участника — запрос, одобрение, вид изнутри после вступления), недоступность учебных групп учителю, обзорные страницы.
- **Предположение (не доказано):** точный алгоритм Заучивания (видно, что mastery-based, внутренняя формула закрыта); наличие текст-экспорта на *своём* модуле (на чужом — нет); «автоподсказки» опираются на внутреннюю базу; **вид учебной группы глазами не-владельца** и наличие/отсутствие одобрения при join-по-ссылке у учебной группы (нужен 2-й ученический аккаунт).
- **Не проверялось (вне сетапа):** офлайн (только приложение), мобильные приложения, новые ИИ-фичи (за вейтлистом).

## C.4. Приложения

### Карта URL
Ученик: `/<id>/flashcards` · `/<id>/learn` · `/<id>/test` · `/<id>/match` · `/blocks/<id>` · `/charms/<id>` · `/blast/<id>` · `/create-set` · `/settings` · `/login` · `/upgrade` · `/explanations` · `/study-guides/upload` · `/features/pomodoro-timer` · `/features/*` · `/study-groups` (список) · `/study-groups/<id>/materials` · `/study-groups/<id>/members`
Учитель: `/latest` (дашборд) · `/create-activity` (назначить задание) · `/class/<id>` (курс: /members, /materials, /activities, /progress)
