## Quizlet

Ссылка: https://quizlet.com/latest

### Профиль

Quizlet: глобальная платформа для создания учебных материалов на основе флеш‑карточек и интервальных повторений. Пользователь собирает пары «термин–определение», «вопрос–ответ» или «визуальный элемент–подпись», а система возвращает к ним через заданные промежутки. Система использует принципы и методики из психологии памяти и мышления, чтобы давать пользователям действительно эффективный способ вспоминать и запоминать изучаемый материал. Первый запуск 17 января 2007 года.

**Платформы**:
- Веб: через официальный сайт. Адаптирован под компьютерные, планшетные, телефонные экраны.
- Мобильное приложение
	- iOS: https://apps.apple.com/ru/app/quizlet-ai-powered-flashcards/id546473125
		- Скачать можно бесплатно
	- Android: https://play.google.com/store/apps/details?id=com.quizlet.quizletandroid&pli=1
		- Скачать можно бесплатно
- Desktop: отдельного клиента нет, используется веб.

**Сегменты**: ученики; учителя (`/teachers`); школы (Quizlet for Schools).

**Локализация**: полный русский интерфейс.

**Позиционирование**: самозаявленный сервис №1 по карточкам.

**Модель доступа**: Freemium.

Free account:
- Управление собственными модулями в неограниченном количестве (модуль состоит из N флеш-карточек)
- Бесплатный поиск по опубликованным модулям
- Запоминание по флеш-карточкам в классическом режиме (вспомнил, открыл, проверил, перешёл к следующей)
- Лимитированный функционал заучивания, тестирования.
- Реклама покупки собственной подписки при работе с некоторыми бесплатными элементами, а также лимитированными.
На бесплатном аккаунте доступ к лимитированным функциям обновляется автоматически каждый день/месяц. То есть за день можно сделать N лимитированных действий, и всего за месяц можно сделать M лимитированных действий.

Paid account (Базовый, от 529 ₽/мес): лимиты сохраняются, снимается реклама. См. [Ценообразование](#ценообразование).

Paid account (Unlimited, от 699 ₽/мес): все лимиты сняты. См. [Ценообразование](#ценообразование).

### Ценообразование

На момент 2026-10-01.

Два вида планов:
- пользователям
- группам учитель-ученики

Пользователям доступны два плана (Базовый и Unlimited), месячный и годовой период. Все планы без рекламы.

| План | Период | Цена | Пробные тесты | Решения из учебников | Раунды заучивания |
|------|--------|------|:-------------:|:--------------------:|:-----------------:|
| Базовый | мес | 529,00 ₽ | 3/мес | 3/мес | 20/мес |
| Базовый | год | 2 325,00 ₽ (193,75 ₽/мес) | 3/мес | 3/мес | 20/мес |
| Unlimited | мес | 699,00 ₽ | ∞ | ∞ | ∞ |
| Unlimited | год | 2 990,00 ₽ (249,17 ₽/мес) | ∞ | ∞ | ∞ |

Unlimited позиционируется как QuizletPlus Unlimited.

Группам учитель-ученики:
- Расчёт производится через калькулятор
- Минимальный платёж: 4 417,50 ₽ / год
	- Для 2-х учителей и 0 учеников
- 85 147,50 ₽ / год
	- Для 2-х учителей и 30 учеников
- В подписку входит
	- Личный кабинет для учителей и учеников
	- Пространство для совместных занятий и игры в образовательные игры

Бесплатный тариф идёт с рекламой и урезан по **числу запусков** Заучивания и Теста, а не по базовому функционалу. Это главный рычаг апселла. Годовой триал длится 7 дней, у месячных подписок триала нет.

### Позиционирование

По маркетинговым лендингам `quizlet.com/ru` (сырьё и цитаты в [quizlet/источники.md](quizlet/источники.md)).

| Ось | Формулировка |
|-----|--------------|
| Категория | Универсальное учебное приложение на основе карточек + учебные активности и решения из учебников |
| Обещание | «Одно учебное приложение для всех предметов и тестов»: учись где угодно, бесплатно |
| Для ученика | Освоить любой материал; персональные тесты и сеансы. Соцдоказательство: 98% говорят, что стали понимать глубже |
| Для учителя | Поднять успеваемость, вовлечь класс играми, сэкономить время на контенте. Соцдоказательство: 90% улучшили результаты |
| Дифференциаторы | Масштаб библиотеки (500M+ модулей); многорежимность; геймификация (Quizlet Live); ИИ-помощь при создании |
| Модель как позиционирование | Freemium; платишь за интенсивность и учительскую аналитику («Прогресс класса») |
| Тон | Доступный, ободряющий; «учёба может быть увлекательной», упор на соревнование и вовлечение |

Развилка аудитории заявлена прямо в hero: «Зарегистрироваться бесплатно» против «Я учитель».

Пробелы: единого слогана-одной-строки на сайте нет (роль УТП играет зонтичное обещание выше); конкурентный фрейм (против Anki/Kahoot/Chegg) прямо не заявлен, выводится из фич.

## Kahoot

Ссылка: https://kahoot.com

### Профиль

Kahoot! работает как игровая платформа обучения (game-based learning). Ядро: live-викторина, где вопрос на общем экране ведущего, а участники отвечают с телефонов, нажимая цветные фигуры. Очки за скорость и верность, между вопросами лидерборд, в конце подиум.

**Платформы**:
- Веб: `kahoot.com` (создание и хостинг), `kahoot.it` (вход игрока по PIN).
- Мобильные приложения: iOS, Android.
- Desktop: отдельного клиента нет, используется веб.

**Сегменты**: школы, высшее образование, бизнес (Kahoot! 360), личное использование, Kahoot! EDU.

**Локализация**: интерфейс многоязычный (в селекторе 55+ языков).

**Развилка аудитории**: при регистрации (Teacher / Professional / Student / Family).

**Модель доступа**: Freemium. Бесплатный Kahoot! Go + платные тарифы. Бесплатный аккаунт жёстко урезан по числу участников и типам вопросов.

### Ценообразование

Тарифы для школ, валюта EUR (RU-цены не снимались). Переключатель месячная/годовая, цены «include tax». Главный рычаг апселла: лимит участников.

| План | Цена (мес, годовой биллинг) | Лимит участников | Ключевое |
|------|------------------------------|------------------|----------|
| Kahoot! Go | 0 | 40 | Classic live, quiz + true/false, готовый контент, flashcards, банк вопросов |
| Kahoot!+ Bronze | €4 (€44/год) | 50 | Базовая ИИ-генерация (3 стр.), review-типы, accuracy experience |
| Kahoot!+ Silver | €8.50–9 (€102/год) | 100 | ИИ из файлов (до 150 стр.), feedback-типы, lecture experience, game experiences |
| Kahoot!+ Gold | €15 (€174.50/год) | 200 | Полный ИИ-тулкит, precision-типы, advanced-отчёты, AccessPass |
| Kahoot! One | €23 (€276/год) | 800 | Все типы вопросов, все режимы, файлы любой длины |

Отдельные линейки: Kahoot! EDU (школы/вузы), Kahoot! 360 (бизнес), Kahoot! One Ultra (крупные брендированные события). Монетизация по лимиту участников + ИИ-фичи + типы вопросов + отчёты. Расхождение с маркетингом: Go заявляет 40 участников, но на реальном бесплатном Teacher-аккаунте доступно только 10 (видел «Max. 10 participants»).
