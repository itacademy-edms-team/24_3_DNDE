# Product Decision Records

Записи продуктовых решений (PDR) по RecallApp. Один файл — одно продуктовое решение: контекст, рассмотренные варианты, выбор и последствия.

## Конвенция

- **Хранение**: все PDR здесь, в `docs/pdr/` (при необходимости перенесём).
- **Имя файла**: `NNNN-имя-pdr-записи.md` со сквозной нумерацией (`0001-`, `0002-`, ...). Нумерация своя, отдельная от ADR.
- **Область решения** указывается полем **Scope** внутри записи.
- **Статусы и правила заморозки тела** — как в [ADR](../adr/README.md) (`proposed` → `accepted` / `rejected` → `deprecated` / `superseded`).
- **Архитектурные решения (ADR)** живут в `docs/adr/`, не здесь.
