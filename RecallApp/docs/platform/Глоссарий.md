# Глоссарий

> Единый словарь доменных терминов: что означает и где определён. Мост к будущей онтологии: она возьмёт термины как классы и отношения. Авторитетный источник модели: [План платформы §2](План%20платформы.md), научных понятий: [Смысловое ядро](../vision/Смысловое%20ядро.md), ролей и прав: [Роли и доступ](Роли%20и%20доступ.md).

## Три оси классификации

Элемент описывают три независимые оси, их легко спутать:

- **Тип элемента**: *что показываем* (флеш-карточка, выбор, пропуск).
- **Класс формата**: *есть ли эталон* (извлекающий / дивергентный).
- **Режим оценки**: *как получили сигнал сложности* (авто-сверка / самооценка / нечёткая).

## Контент (Слой 1)

| Термин | Определение | Где |
|--------|-------------|-----|
| Набор | Коллекция Элементов, принадлежит Пользователю. Проходится и без SRS | План §2 |
| Элемент набора | Атом контента; тип задаёт поля и способ проверки. Контракт: предъявить → принять ответ → проверить → вернуть Результат проверки. Напр., флеш-карточка предъявляет лицо, принимает ответ, сверяет с оборотом, возвращает верно/неверно | План §2 |
| Тип элемента | Вид Элемента (флеш-карточка, с выбором, пропуски и т.д.) | План §2 |
| Флеш-карточка | Тип элемента: лицо, оборот, медиа, направление(я) | План §2 |
| Направление карточки | Одно из направлений проверки карточки (термин→определение или обратно). Гранулярность SRS-записи | План §2, §4 |
| Результат проверки | `{исход: верно/неверно/частично, опц. сигнал сложности}`. Контракт между Слоем 1 и Слоем 2 | План §2 |
| Класс формата | Извлекающий (есть эталонный ответ, кормит SRS) или дивергентный (ответ открытый, эталона нет, вне SRS) | План §2, §4 |
| Режим оценки | Как получен сигнал сложности: авто-сверка / самооценка / нечёткая | План §4 |
| Группа наборов | Объединение наборов | План §2 |
| Учебная группа | Сообщество пользователей с подборками наборов/групп | План §2 |

## Обучение и SRS (Слой 2)

| Термин | Определение | Где |
|--------|-------------|-----|
| SRS | Распределённое повторение с растущими интервалами; показывает материал перед моментом забывания | Смысловое ядро |
| SRS-запись | Запись планировщика повторений: SRS-состояние одной проверяемой единицы (интервал, дата показа, сложность). Ссылается на Элемент, направление карточки или пропуск. Только для извлекающих элементов. Ранее «Цель повторения» | План §2 |
| Чередование (interleaving) | Смешивание разных элементов/типов в одной сессии; обучение различению | Смысловое ядро, План §2 |
| Многоформатная проверка | Показ одного элемента разными допустимыми форматами по повторам | План §2, §3 |
| Сессия | Прогон режима (заучивание/тест/игра); может затронуть несколько элементов | План §2 |
| Заучивание | Режим mastery-раундов поверх расписания | План §3 (CORE-06) |

## Пользователь и мультиплеер

| Термин | Определение | Где |
|--------|-------------|-----|
| Пользователь | Зарегистрированный аккаунт; основная роль публичного приложения: создаёт, проходит, публикует, копит SRS. Роли и права — в отдельном документе | Роли и доступ, План §2 |
| Матч | Realtime или асинхронная сессия на нескольких игроков над набором | План §2 |
| Игрок | Участник матча, может быть гостем без аккаунта | План §2 |
| Команда | Группировка игроков в матче | План §2 |

## Процесс и планирование

| Термин | Определение | Где |
|--------|-------------|-----|
| ID фичи | Префикс домена (`CORE`, `SRS`, `CREATE`, `ORG`, `GAME`, `MP`, `ACCT`, `TEACH`) + номер. Канонический реестр | Бэклог |
| Размер (S/M/L) | Оценка объёма: `S` ≈ полнедели, `M` ≈ неделя, `L` ≈ две недели | Бэклог |
| Фаза | MVP / core / social / ext / off-scope: крупный статус фичи по горизонту | План §3 |
| PDR / ADR | Продуктовое / архитектурное решение (Decision Record) | будущая фаза |

## Соответствия (синонимы и источники)

| В наших доках | У конкурентов / в науке | Примечание |
|---------------|-------------------------|------------|
| Набор | «модуль» (Quizlet), «kahoot» (набор вопросов) | один смысл |
| Тип элемента | «Формат» (Смысловое ядро) | «формат» = способ подачи = тип элемента |
| SRS-запись | «card» с расписанием (Anki) | у нас отделена от контента; ранее называлась «Цель повторения» |
| Элемент набора | «карточка» (Quizlet как атом) | у нас карточка лишь один тип |
| Последовательность | «Ранжирование / порядок» (Смысловое ядро) | один смысл |
| Числовой ответ | «Числовая оценка / шкала» (Смысловое ядро) | один смысл |
