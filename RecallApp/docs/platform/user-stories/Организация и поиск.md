## ORG-01 Папки / группы наборов

Личная организация контента. Речь о «группе наборов» (подборка для себя), не об «учебной группе» (сообщество пользователей) — это разные сущности из [Плана §2](../План%20платформы.md). Роль — Пользователь.

### ORG-01-US-1

**Как** Пользователь, **я хочу** создать группу наборов, **чтобы** объединять связанные материалы в единые тематические подборки.

Критерии приёмки:
- доступно создание группы наборов;
- у группы есть обязательное название;
- пустое название не сохраняется, показывается подсказка;
- группа принадлежит текущему пользователю.

### ORG-01-US-2

**Как** Пользователь, **я хочу** добавлять и убирать наборы из группы, **чтобы** управлять составом группы.

Критерии приёмки:
- в группу можно добавить свои и сохранённые наборы (механизм сохранения чужих — ORG-04);
- набор можно убрать из группы;
- один набор может состоять в нескольких группах одновременно;
- убирание набора из группы не удаляет сам набор.

### ORG-01-US-3

**Как** Пользователь, **я хочу** переименовать и удалить группу, **чтобы** держать структуру своих подборок в порядке.

Критерии приёмки:
- группу можно переименовать;
- группу можно удалить с подтверждением;
- удаление группы не удаляет входящие в неё наборы.

### ORG-01-US-4

**Как** Пользователь, **я хочу** видеть свои наборы и группы списком, **чтобы** быстро находить нужное.

Критерии приёмки:
- свои наборы и группы видны списком;
- из списка можно открыть набор или группу;
- поиск по публичной библиотеке сюда не входит, это отдельная фича ORG-03.

## ORG-02 Шаринг по ссылке

Публикация набора и доступ по ссылке. Три состояния видимости. По ссылке гость видит только фрагмент набора (первые несколько элементов); прохождение, сохранение и прогресс — после входа ([Роли и доступ](../Роли%20и%20доступ.md), «Границы»).

### ORG-02-US-1

**Как** Пользователь, **я хочу** задать видимость набора (приватный / по ссылке / публичный), **чтобы** контролировать доступность набора другим.

Критерии приёмки:
- у набора три состояния: приватный, по ссылке, публичный;
- приватный виден только владельцу;
- по ссылке доступен любому вошедшему пользователю со ссылкой, в библиотеке не появляется;
- публичный доступен по ссылке и попадает в публичную библиотеку и поиск (ORG-03);
- по умолчанию набор приватный.

### ORG-02-US-2

**Как** Пользователь, **я хочу** получить ссылку на набор и поделиться ею, **чтобы** дать другим доступ к материалу.

Критерии приёмки:
- ссылка доступна, когда набор в состоянии «по ссылке» или «публичный»;
- ссылку можно скопировать;
- для приватного набора ссылка не выдаётся: сперва нужно сменить состояние (US-1).

### ORG-02-US-3

**Как** Гость, **я хочу** посмотреть фрагмент набора по ссылке, а для прохождения войти, **чтобы** оценить набор до регистрации.

```
Сценарий: открытие набора по ссылке
  Дано: у меня есть ссылка на доступный набор, я не вошёл
  Когда: я открываю ссылку
  Тогда: я вижу фрагмент набора — первые несколько элементов, без возможности их пройти
  Когда: я пытаюсь пройти набор, сохранить или продолжить
  Тогда: система требует войти или зарегистрироваться
  Когда: я вхожу или регистрируюсь
  Тогда: набор открывается для прохождения
```

Дополнительно:
- без входа доступен только предпросмотр фрагмента, не весь набор и не прохождение;
- объём фрагмента (число элементов) настраивается;
- редактировать чужой набор нельзя; для изменений делается копия через ORG-06, которая правится уже как свой набор.

### ORG-02-US-4

**Как** Пользователь, **я хочу** отозвать доступ по ссылке или вернуть набор в приватный, **чтобы** закрыть доступ к набору другим пользователям.

Критерии приёмки:
- владелец может сменить состояние набора обратно на приватный;
- после закрытия доступа ссылка перестаёт открывать набор другим;
- потеря доступа применяется и к тем, кто открывал набор раньше.

## ORG-03 Публичная библиотека + поиск

Поиск по индексу публичного контента и материала учебных групп пользователя. Гость в библиотеку не ходит: материал за логином. Рейтинг пока не считается, сортировка по объективным полям. Роль — Пользователь.

### ORG-03-US-1

**Как** Пользователь, **я хочу** искать публичные наборы и группы по запросу, **чтобы** находить готовый материал для изучения.

```
Сценарий: поиск по библиотеке
  Дано: я на экране поиска
  Когда: я ввожу запрос
  Тогда: показываются публичные наборы и группы, подходящие запросу
  И: в выдачу входит материал учебных групп, в которых я состою
```

Дополнительно:
- индексируются публичные наборы и группы наборов, а также материал учебных групп пользователя;
- приватные и доступные только по ссылке в библиотеку не попадают;
- учебные группы как объект поиска — только свои.

### ORG-03-US-2

**Как** Пользователь, **я хочу** видеть в выдаче, что за набор (название, автор, размер, тема), **чтобы** выбрать подходящий, не открывая каждый.

Критерии приёмки:
- у каждого результата видно название, автора, размер и тему или метки;
- видно, набор это или группа;
- данных выдачи достаточно для выбора без открытия.

### ORG-03-US-3

**Как** Пользователь, **я хочу** открыть найденный публичный набор, **чтобы** начать его учить.

```
Сценарий: открытие из выдачи
  Дано: в выдаче есть публичный набор
  Когда: я открываю его
  Тогда: набор открывается для прохождения
```

### ORG-03-US-4

**Как** Пользователь, **я хочу** фильтровать и сортировать выдачу, **чтобы** быстрее сузить окно поиска до нужных результатов.

Критерии приёмки:
- выдачу можно фильтровать (тип: набор или группа, размер);
- сортировка по дате, размеру и названию;
- сортировки по популярности или рейтингу нет (пока нечем считать).
