## GAME-03 Викторины

Одиночный игровой режим поверх теста с выбором: таймер, очки, стрик правильных. Мультиплеерные матчи — отдельная фича MP-02. Нейросетевая оценка свободных ответов — off-scope. Роль — Пользователь.

### GAME-03-US-1

**Как** Пользователь, **я хочу** запустить викторину по набору, **чтобы** проверить свои знания в игровом формате.

```
Сценарий: запуск викторины
  Дано: открыт набор
  Когда: я запускаю викторину
  Тогда: начинается игровой прогон вопросов с таймером и очками
```

### GAME-03-US-2

**Как** Пользователь, **я хочу** угадывать термин по описанию и описание по термину, **чтобы** тренировать материал в обе стороны.

Критерии приёмки:
- доступно угадывание термина по описанию (дано определение);
- доступно угадывание описания по термину (дано термин);
- проверка идёт авто-сверкой или выбором;
- нейросетевая оценка свободных ответов — off-scope.

### GAME-03-US-3

**Как** Пользователь, **я хочу** видеть счёт и итог викторины, **чтобы** оценить свои полученные результаты.

Критерии приёмки:
- по ходу викторины виден счёт и стрик правильных;
- по итогу показан результат;
- результат по извлекающим элементам кормит SRS-записи.

## GAME-01 Достижения

Разблокируемые цели за учебные события. Два уровня: общие (по всей платформе) и по набору (привязаны к конкретному набору). Конкретный каталог достижений задаётся при реализации. Пересечение со стриками и ежедневными наградами — фича GAME-02. Роль — Пользователь.

### GAME-01-US-1

**Как** Пользователь, **я хочу** получать достижения за учебные события, **чтобы** видеть признание своих усилий.

```
Сценарий: разблокировка достижения
  Дано: я выполняю учебные действия
  Когда: наступает событие, закрывающее условие (усвоил набор, стрик дней, первый матч)
  Тогда: достижение разблокируется и отмечается полученным
```

Дополнительно:
- достижения бывают общие и привязанные к набору;
- конкретный каталог задаётся при реализации.

### GAME-01-US-2

**Как** Пользователь, **я хочу** видеть список своих достижений (полученные и ещё закрытые), **чтобы** понимать, что уже сделал и к чему стремиться.

Критерии приёмки:
- виден список достижений: полученные и ещё закрытые;
- у закрытого достижения видно условие разблокировки;
- секретные достижения — опционально, позже.

### GAME-01-US-3

**Как** Пользователь, **я хочу** получать уведомление в момент разблокировки, **чтобы** замечать прогресс сразу.

Критерии приёмки:
- в момент разблокировки показывается уведомление;
- уведомление появляется поверх текущего экрана, не только в списке достижений;
- уведомление можно закрыть.

### GAME-01-US-4

**Как** Пользователь, **я хочу** получать достижения, привязанные к конкретному набору, **чтобы** отмечать прогресс по отдельному материалу.

Критерии приёмки:
- у набора могут быть свои достижения, привязанные к нему;
- наборные достижения видны в контексте набора;
- общие и наборные достижения разделены.

## GAME-02 Награды / стрики

Ежедневные награды и серии занятий (стрики). День стрика засчитывается за учебную активность, а не за простой вход. Дополнительный мотив возвращаться к запланированным повторениям (ядро продукта). Заморозка стрика — опционально, позже. Зависит от GAME-01. Роль — Пользователь.

### GAME-02-US-1

**Как** Пользователь, **я хочу** поддерживать ежедневный стрик занятий, **чтобы** иметь дополнительную мотивацию не бросать регулярную практику.

```
Сценарий: ведение стрика
  Дано: я занимаюсь по дням
  Когда: я выполняю учебную активность в течение дня
  Тогда: день засчитывается в стрик
  Когда: день прошёл без учебной активности
  Тогда: стрик сбрасывается
```

### GAME-02-US-2

**Как** Пользователь, **я хочу** получать ежедневную награду за занятие, **чтобы** иметь повод возвращаться каждый день.

```
Сценарий: ежедневная награда
  Дано: начался новый день
  Когда: я выполняю учебную активность
  Тогда: я получаю ежедневную награду
```

### GAME-02-US-3

**Как** Пользователь, **я хочу** видеть свой текущий стрик и прогресс к награде, **чтобы** следить за прогрессом по серии.

Критерии приёмки:
- виден текущий стрик (сколько дней подряд);
- виден прогресс к следующей награде;
- стрик служит дополнительным мотивом возвращаться к запланированным повторениям, счёт идёт по факту активности.
