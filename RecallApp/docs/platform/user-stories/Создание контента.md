## CREATE-01 Ручное создание набора

Базовый редактор наборов и флеш-карточек. Прочие типы элементов (выбор, пропуски, сопоставление и т.д.) создаются в своих фичах. Роль везде — Пользователь.

### CREATE-01-US-1

**Как** Пользователь, **я хочу** создать новый набор с названием и описанием, **чтобы** собрать материал для изучения.

Критерии приёмки:
- доступно создание нового набора;
- название обязательно, описание опционально;
- пустое название не сохраняется, показывается подсказка;
- новый набор принадлежит текущему пользователю и по умолчанию приватный (состояния набора — ORG-02).

### CREATE-01-US-2

**Как** Пользователь, **я хочу** добавить карточку с термином, определением и медиа, **чтобы** наполнить набор контентом.

```
Сценарий: добавление карточки
  Дано: открыт редактор набора
  Когда: я ввожу термин и определение и добавляю карточку
  Тогда: карточка появляется в наборе
  И: редактор готов принять следующую карточку
```

Дополнительно:
- к стороне карточки можно прикрепить медиа;
- карточка с пустыми термином и определением не добавляется.

### CREATE-01-US-3

**Как** Пользователь, **я хочу** редактировать и удалять карточки, **чтобы** править ошибки и чистить набор.

Критерии приёмки:
- любую карточку набора можно открыть на редактирование;
- правки термина, определения и медиа сохраняются;
- карточку можно удалить с подтверждением;
- удаление убирает её из набора.

### CREATE-01-US-4

**Как** Пользователь, **я хочу** менять порядок карточек, **чтобы** расположить материал логично.

Критерии приёмки:
- порядок карточек можно менять (перетаскивание или кнопки);
- новый порядок сохраняется;
- при прохождении набора карточки идут в заданном порядке.

### CREATE-01-US-5

**Как** Пользователь, **я хочу** быстро создать одиночную карточку, **чтобы** закинуть материал, не заводя набор вручную.

```
Сценарий: быстрая одиночная карточка (вариант C)
  Дано: я хочу добавить карточку, не открывая набор
  Когда: я создаю одиночную карточку
  Тогда: система заводит обычный набор с дефолтным именем и кладёт карточку в него
  И: этот набор виден в моём списке и доступен для переименования
```

Скрытых служебных наборов не создаётся: одиночная карточка всегда живёт в обычном наборе.

### CREATE-01-US-6

**Как** Пользователь, **я хочу** переименовать или удалить набор, **чтобы** управлять своими наборами.

Критерии приёмки:
- набор можно переименовать;
- набор можно удалить с подтверждением;
- удаление набора удаляет и его карточки;
- если набор опубликован, перед удалением показывается предупреждение.

### CREATE-01-US-7

**Как** Пользователь, **я хочу** автосохранение черновика набора, **чтобы** не терять работу при большом объёме материала.

```
Сценарий: автосохранение черновика
  Дано: я наполняю набор материалом
  Когда: я добавляю и правлю карточки, не нажимая «сохранить»
  Тогда: изменения периодически сохраняются как черновик
  Когда: я ухожу и возвращаюсь к набору
  Тогда: черновик восстанавливается с несохранёнными изменениями
```

Дополнительно:
- закрытие вкладки или потеря соединения не теряют уже сохранённый черновик.

## CREATE-02 Импорт текстом

Создание карточек вставкой текста с настраиваемыми разделителями. Роль — Пользователь.

### CREATE-02-US-1

**Как** Пользователь, **я хочу** вставить текст с парами «термин–определение» и импортировать, **чтобы** быстро создать набор из готового списка.

```
Сценарий: импорт пар из текста
  Дано: открыт импорт текстом
  Когда: я вставляю текст с парами и запускаю импорт
  Тогда: каждая распознанная пара становится карточкой (термин и определение)
```

Дополнительно:
- пустые строки пропускаются;
- строка без разделителя помечается как нераспознанная.

### CREATE-02-US-2

**Как** Пользователь, **я хочу** настроить разделители между термином и определением и между карточками, **чтобы** импортировать текст в любом исходном формате.

Критерии приёмки:
- настраивается разделитель между термином и определением (таб, запятая, свой);
- настраивается разделитель между карточками (новая строка, пустая строка, свой);
- смена разделителя сразу обновляет разбор.

### CREATE-02-US-3

**Как** Пользователь, **я хочу** увидеть предпросмотр распознанных карточек до импорта, **чтобы** поймать ошибки разбора до создания.

Критерии приёмки:
- до импорта виден предпросмотр распознанных карточек;
- показано число распознанных карточек;
- нераспознанные строки подсвечены;
- импорт можно отменить после предпросмотра.

### CREATE-02-US-4

**Как** Пользователь, **я хочу** импортировать в новый или существующий набор с решениями для дубликатов, **чтобы** дополнять наборы, а не только создавать.

Критерии приёмки:
- импорт возможен в новый набор или в существующий;
- при добавлении в существующий совпадение с имеющейся карточкой считается дубликатом;
- для дубликата доступны решения: пропустить, добавить всё равно, заменить;
- выбранное решение применяется ко всему импорту.
