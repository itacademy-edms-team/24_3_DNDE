## Платформа для заучивания материала

[см. пример](https://quizlet.com/ru)

Выбранная тема: "Разработка веб-платформы для запоминания учебного материала с поддержкой различных образовательных методик".

Потенциально хорошая актуальность. Можно сослаться на книги по педагогике и прочему. Личное мнение, что потребность в заучивании материала есть всегда.

В первую очередь реализовать заучивание с помощью карточек. Затем можно расширить на другие способы заучивания.

Создание и публикация своих собственных наборов карточек. Возможность делиться ими по ссылке. Один набор содержит много карточек.

Объединение наборов карточек в группу. Одна группа содержит много наборов.

Учебные группы для пользователей. Содержат подборки из наборов карточек или подборки из групп.

Поиск по вышеперечисленному.

Хороший потенциал для геймификации.
- достижения
- ежедневные награды
- соревнования по заучиванию
	- вдвоём
	- группами (1 большой или несколькими)
- викторины, как в [Kahoot!](https://kahoot.com)
	- угадывание по описанию
	- угадывание по терминам (можно прикрутить нейронку для оценки ответов по эталону: правильно/неправильно)
- объясни и угадай
	- первый игрок получает определение термина или сам термин. Если получил определение, то пишет термин; если термин, то его определение.
	- второй игрок получает результат первого и пытается также объяснить материал. Если получил определение, то пишет термин; если термин, то его определение.
	- и так далее до последнего игрока
	- Пример: игрок 1 получает термин «фотосинтез», пишет определение. Игрок 2 видит только это определение и восстанавливает термин. Игрок 3 снова получает определение, и так по цепочке. В конце видно, на каком звене смысл поплыл.
	- чтобы не ждать долго другим игрокам, им можно давать другие термины.
	- Расширение: каждому игроку выдаём индивидуальный набор, который потом по кусочкам расшаривается остальным. На выходе у каждого своя цепочка терминов и определений. Никто не простаивает в ожидании хода.
	- В конце можно будет какую-нибудь статистику посмотреть. В частности чтобы увидеть, кто накосячил и кому нужно ещё повторить материал.
- восстановление текста с прогрессированием
	- Пользователь восстанавливает текст, в котором каждый раз становится всё больше пропусков, вплоть до полного восстановления текста.

Идеи по функционалу:
- словарь «термин–определение»: для быстрого создания новых коллекций.
